# 初始化重置脚本 SPEC

## 目标

提供一个 Windows 一键脚本，让项目交给别人之前能快速恢复到“未初始化”状态，避免因保留 `.env` 或旧超级管理员而直接跳过初始化向导。

## 行为

执行后会：

- 连接当前数据库
- 将所有未删除的 `super_admin` 降级为 `member`
- 删除 `server/session.json`
- 删除项目根目录 `.env`
- 输出下一步提示：重新启动后会进入安装向导

## 设计原则

- 不删除普通业务数据
- 不直接清空整库
- 若数据库连接失败，不删除 `.env`，避免留下半完成状态

## 变更文件

- `server/scripts/reset-to-init.js`（入口脚本，由运维面板「重置初始化」动作 / `start-services.ps1` 菜单 1 直接调用）
