# 07 · 运维后台使用说明

独立于主站（3456）的轻量运维面板，端口 **3457**，默认仅监听 `127.0.0.1`。用于服务启停、
MySQL 直连管理、数据备份、日志查看、安全配置等日常运维。仅适用于 **裸机 / 宝塔 / Windows 本机** 部署
（Docker 容器镜像不含 `panel/` 目录）。

## 1. 启动与登录

```bash
# Windows（仓库根目录）
jingtu.bat panel          # 或 start-panel.bat 见下
# Linux
bash jingtu.sh            # 选择运维面板入口
```

传统入口：`start-panel.bat start|stop|status`（双击进交互菜单：1 开启 / 2 关闭 / 3 状态 / 0 退出）。

- 首次使用设置面板管理密码（≥8 位），密码 PBKDF2 10 万次迭代 + 16 字节随机盐。
- 登录后签发内存令牌，12 小时滑动过期；连续 5 次失败锁定 15 分钟。
- 高危操作（清空数据/恢复/释放端口/重置超管）需输入确认短语双重校验。
- 忘记面板密码：删除 `panel/panel-auth.json` 后重启面板即可重置。

## 1.5 与主站联动：按需启动与空闲自动关闭

主站「后台 → 网站管理 → 运维面板」入口会**按需拉起**面板：

- 点击按钮 → 主站 `POST /api/ops/start` 确保面板进程就绪后再打开 `/ops/`，全程无需手动 `start-panel.bat`。
- 面板页面打开期间每 3 分钟心跳保活，页面开着不会被自动关闭。
- 关闭面板页面后，主站检测到空闲超过 `PANEL_IDLE_MINUTES`（默认 **20 分钟**）自动关闭面板进程并回收内存；
  下次点击入口再自动拉起（循环）。可用 `GET /api/ops/status` 查看运行/空闲状态。
- 调参：`PANEL_IDLE_MINUTES`（空闲分钟）、`PANEL_IDLE_CHECK_SECONDS`（检查周期）、`PANEL_START_POLL_MS`（健康轮询）。

## 2. 功能页签

| 页签 | 功能 |
|---|---|
| 仪表盘 | 环境/磁盘/服务状态概览 |
| 服务管理 | MySQL / Nginx / NodeServer 启停、端口检测与释放 |
| 网站管理 | 直连 MySQL：用户搜索/禁封/重置密码/更新配置 |
| 数据备份 | uploads 打包备份/下载/恢复/清空、配置导出 |
| 日志中心 | site.log / panel.log 查看 |
| 系统工具 | 环境检查/磁盘/站点打包/缓存清理/重置初始化 |
| 安全配置 | 修改面板密码、局域网访问开关、重置超级管理员密码 |
| 审计日志 | 面板操作留痕 |

## 3. 激活码管理

`panel` 与主站 `/api/admin/activation-codes/*` 共用同一离线存储文件
（`server/data/activation-codes.json`，可由 `ACTIVATION_CODES_FILE` 覆盖），任一端操作即时生效。

## 4. 常见问题

| 问题 | 处理 |
|---|---|
| 控制台中文乱码 | 文件须 UTF-8 with BOM；已设置 `[Console]::OutputEncoding=UTF8` + chcp 65001 |
| 端口 3457 被占用 | 服务管理页「释放端口」或 `jingtu.ps1` 相关动作 |
| 网站管理不可用 | 该模块依赖 MySQL 在线，检查数据库服务状态 |
| 面板密码与网站账号 | **互相独立**，不要混淆 |

> 目录：`panel/panel-server.js`（3457 HTTP）+ `panel-api.ps1`（执行层返回单行 JSON）+ `panel/public/index.html`（单文件 UI）。
