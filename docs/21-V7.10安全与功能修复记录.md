## 一、运维脚本 `jingtu.ps1` — 隐藏关键 bug 修复

**问题**：干净的 `restart` 跑到 `Start-Nginx`/`Start-Site`（内部用 `Start-Process -RedirectStandard*`）时崩溃：
`System.ArgumentException: 已添加项。字典中的关键字:"Path" 所添加的关键字:"PATH"`。

**根因**：宿主 PowerShell 环境块中存在大小写重复的变量（`Path`/`PATH`/`path` 三套）。`Start-Process -Redirect*` 在构建子进程环境字典（大小写不敏感的 `StringDictionary`）时撞键抛异常。此前从未暴露——旧版 restart 总在 MySQL 步骤挂掉、站点一直是手动拉起的。

**修复**：新增纯 PowerShell 的 `Repair-Environment` 函数并在脚本入口调用：
- 用已合并（大小写不敏感）的环境变量名枚举（`[System.Environment]::GetEnvironmentVariables().Keys`，**不用 `Get-ChildItem env:`**——它在重复键时会本身抛异常）；
- 对每个变量先 `while` 删光所有大小写变体再 set 一次（带 32 次上限防死循环），单变量 `try/catch` 兜底「值过长」。
- 初版用 `Add-Type` 写 C# 归一化，被沙箱拦截（运行时编译 .NET）且在子进程挂死兜不住，**已彻底弃用，改为纯 PS**。

**其他健壮性（上一轮已就位）**：`$NoBrowser` 守卫、`Stop-NodeByScript`、MySQL 服务优先级、`Test-Port` IPv6 匹配。

**验证**：`jingtu.ps1 restart` 端到端跑通（停旧站 → 拉 MySQL 服务 → 起 Nginx 80 → `Start-Process -Redirect` 起 Node 3456），EXIT=0，无残留进程。

## 三、整站功能/安全深审与修复

对前后端做两轮并行深审（后端 routes + 前端 17+ 模块）。此前担心的字段对齐（eventTime↔time、avatarUrl、displayName、newName、permission-groups）经验证**已全部对齐，非问题**。真正修掉的缺陷如下。

### 🔴 P0 — 越权（IDOR）
- **WebSocket 群聊历史越权枚举**（`server/ws_service.js` `handleHistoryRequest` 群分支）：任意登录用户发 `{type:'history:request', chatType:'group', targetId:<任意群ID>}` 即可读取私密/邀请制群全部聊天记录（对应 HTTP 接口有成员校验，WS 通道漏了）。修复：查询前先查 `chat_group_members`，非成员返回 `history:error / FORBIDDEN`。

### 🟠 P1 — 隐私 / 功能缺口
1. **封禁用户仍可报名活动**（`events.js` `/sign`、`/unsign` + 前端 `events.js`）：此前 `/me/profile` 漏返回 `banned`，前端守卫 `role!=='grief'` 为死代码（无 grief 角色），后端从不查封禁。修复：`users.js` 补返回 `banned`；`/sign`、`/unsign` 加封禁校验（命中 403）；前端守卫改为 `!currentUser.banned`。
2. **实时位置隐私开关形同虚设**（`ws_service.js` 位置广播）：关闭 `location_visible` 后仍向全体在线用户推 GPS。修复：广播前查 `location_visible`，仅开启才广播（落库条件本就有，现已前后一致）。
3. **私信接收方无法删除/编辑**（`chat.js` 私信编辑/删除）：仅发送方可操作，接收方被骚扰后无法清理。修复：`sender_id !== uid && receiver_id !== uid` 才拒绝。
4. **群管无法撤回成员消息**（`chat.js` 群消息编辑/删除）：仅发送方，群主/管理员无法处置违规消息。修复：群主（`creator_id`）或群管理员（`is_admin`）可操作。
5. **存储型 XSS（VRC 名片）**（`members.js`）：信任等级 `title` 属性与 `innerHTML` 未转义（数据源自 VRChat/DB，可控）。修复：改 `escAttr()`/`esc()`。
6. **生日派对状态永远「即将开始」**（`birthday.js`）：用后端从不返回的 `p.isActive`。修复：改为基于 `time`/`endsAt` 时间派生 `isActive`。

### 🟡 P2 — 健壮 / 隐性缺陷
1. **存储型 XSS（编辑动态预览）**（`posts.js`）：`mediaUrl` 直接拼 `innerHTML` → 改 `escAttr(mediaUrl)`。
2. **SVG 头像注入**（`server.js` 头像生成）：`text` 加 XML 转义（`&<>`）。
3. **输入健壮性**（`events.js` 标题、`album.js` 描述）：补 `typeof === 'string'` 守卫（非字符串访问 `.length` 会 500）。
4. **聊天静默失败**（`chat.js`）：`catch{/*静默*/}` → `toast(...)` 提示加载失败。
5. **改名理由丢失**（`admin.js` + `name_change_requests`）：读取/写入/返回 `reason`（表本就有该列，此前代码未用；前端 `profile.js` 已发、`admin-vrc.js` 已 `esc` 渲染）。
6. **全局封禁校验 fail-open**（`server.js` 会话中间件）：DB 异常时「放行」→ 改 fail-closed（返 503）。
7. **`/my` 权限接口静默吞错**（`permission_groups.js`）：改 `console.error` + 返 500。
8. **权限组 `:userId` 路由未校验**（`permission_groups.js`）：补 `parseInt` + 整数/正数校验。
9. **群消息 `msgType`/`lat`/`lng` 未校验**（`chat.js`）：`msgType` 白名单，`location` 类型强制校验坐标合法。
10. **主题「自动」模式空操作**（`theme.js` `applyTheme`）：auto 下固定写 `data-theme='auto'` 导致时段切换不生效 → 统一用 `computeBrightness` 写 `dark`/`light`。
11. **两处静默失败**（`album.js` 分类加载、`admin-vrc.js` 系统配置加载）：失败加 `toast` 提示。
