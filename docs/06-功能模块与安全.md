## 2. 认证与权限

- bcrypt cost 12；密码强度 ≥8 位 + 大小写 + 数字（前后端口径存在差异，以实际校验为准）。
- 角色阈值：member(2) / admin(3) / super_admin(4)；`requireAdminCompat` = admin 及以上。
- **角色归一化与实时判定**：`users.role` 仅接受 member/admin/super_admin 三值，非法值写入时归一为 member；`currentRole(req)` / `requireRole(...)` **每次实时回查数据库、不信任会话快照**，角色被降级后旧会话立即失去高权限（20261021g 修复 L1/L3）。
- VRChat 凭据：QQ 用 AES-256-CBC、VRChat Cookie 用 AES-256-GCM（`ENCRYPT_KEY` 64hex）。
- VRChat 绑定/登录（`server/auth_vrc_service.js`）：两步登录（密码 → 2FA）、绑定三重限流、
  2FA 失败计数防爆破、cookie 加密入 session。
- 系统 VRChat 账号（`server/vrc_auth.js`）：cookie 双候选降级（用户绑定 → 系统账号）、自动重登熔断/退避
  （F-30，可 TOTP 自动完成）、凭据 AES-256-GCM 加密落盘、软性过期（`vrc_cookie_expire_days`）。
  历史缺陷 P1/P2/P3 已于 2026-10-09 修复；后续质检与加固记录并入本文档体系（详见 §3 安全中间件）。

## 4. 信任光环

### 4.1 功能与数据

- 信任光环（trust ring）：按 VRChat 信任等级在头像外圈渲染彩色光环，色阶取自 `trustColorOf()`（灰 negative / 白 visitor / 蓝 new / 绿 user / 黄 known / 橙 trusted / 紫 vetted / 红粉 veteran / 金粉 legend；空值回退默认金环 `DEFAULT_TRUST_COLOR`）。
- 数据层：`group_roster.trust_level / trust_level_cn`（定时/全量同步回填，**只升不降**）；`users.halo_visible TINYINT DEFAULT 1`（光环可见性开关）；`users.trust_level / trust_checked_at`（**V6.17**：已绑定 VRChat 但名册无该用户记录时的自身信任等级缓存，由 VRChat 绑定瞬间 / 个人页 `/me/profile` 打开时后台回填，避免光环恒为默认金色）。
- 渲染位置：VRC 群组成员卡片、网站成员卡片/头像、成员弹窗、地图成员点位、我的信息头像、导航栏右上角头像。实现为 `has-trust-ring` class + CSS 变量 `--tc`（环色）。
- 自身信任等级数据源优先级：**群名册 `group_roster`（定时同步，最新）→ `users.trust_level`（绑定/个人页回填缓存，6h 去重刷新）→ 默认金环**。

### 4.2 光环开关语义（20261019o 起）

「我的信息 → 头像显示设置 → 显示信任光环」开关的语义是：

- **控制「我的光环是否对别人可见」**，即每个用户只管理自己光环的可见性；
- 浏览别人的光环时，按**对方自己**的 `halo_visible` 设置渲染（后端 `/api/group/members`、`/api/users/list` 均已下发每个成员的 `haloVisible`；未绑定网站账号的 VRChat 成员默认显示光环）；
- 一个人关闭开关**不会**导致全站光环消失（修复前为全局开关：任一用户关闭后所有成员光环均不渲染）；
- 自己看自己（导航栏头像 / 我的信息头像）始终按自己的开关渲染。

### 4.3 交互细节

- 悬停放大：群组成员卡片悬停时**整个头像容器**（`.gm-avatar-wrap`，含光环）一起 `scale(1.08)` 放大，避免仅放大头像导致光环被裁/被遮挡（20261019o 修复）。
- 头像加载失败：代理失败 → 直连重试一次 → 仍失败回退 `/api/avatar/default`（`ui.js __avatarFail` 重试链），光环不受影响。

### 4.4 动画与「减少动态效果」

- 站点尊重系统/浏览器的 `prefers-reduced-motion: reduce`（无障碍规范）：开启后全站 CSS 动画与过渡立即结束，**视觉上像"动画卡住/静止"**——桌面端常见（Windows 关闭动画效果 / 浏览器开启减少动态），手机端通常未开所以动画正常。
- 用户可在 **主题面板（🌙）→ 动态效果 → 强制开启** 强制恢复全站动画（持久化 `localStorage.jingtu_anim='on'`，实现 `loader.js` force-anim + `theme.js` 开关）；也可用 URL 参数 `?anim=on` / `?anim=off`。

## 5. 已知边界（非缺陷，设计如此）

- 单进程单实例（CSRF/限流计数/WS 在线映射/VRC 状态在内存）——**禁止 cluster/多副本**。
- 直播为元数据模式，无推流/转码/HLS 后端。
- 邮件/每日汇总依赖 `SMTP_*` 配置，未配置时静默跳过。
- CSP 内联脚本依然存在（index/migration 页内联），未达严格 CSP。
