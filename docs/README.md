## 三分钟起站（Docker 面板一键）

1. 打开服务器 Docker 面板（1Panel / 宝塔「Docker → Compose」）→ **创建项目**。
2. 项目名称填 `jingtu-web`，把仓库根目录 [`docker-compose.standalone.yml`](../docker-compose.standalone.yml) 的内容粘贴/上传到「docker-compose.yml」。
3. 勾选 **「创建项目后立即启动」** → 确认。等待拉镜像 + 建库（约 1~2 分钟）后访问 `http://服务器IP:3456`。

> ⚠️ 一键版内置「体验默认密钥」，**正式使用前请修改** MySQL 密码 / `SESSION_SECRET` / `ENCRYPT_KEY`（见 [01-快速开始.md §1.3](01-快速开始.md#13-一键版安全提示必改项)）。

### 飞牛 fnOS 部署

飞牛「Docker → 项目」使用仓库根目录 [`docker-compose.fnos.yml`](../docker-compose.fnos.yml)（存储空间3 绑定挂载 + init 权限容器，详见 [DEPLOY.md §1.6](../DEPLOY.md#16-飞牛-fnos-单文件部署)）。
